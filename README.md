# Dashboard MORA (EBDI Operations Dashboard)

Dashboard Eksekutif dan Operasional Keuangan Transfer EBDI - Monitoring Cash Flow, Biaya Wilayah, dan Rekapitulasi Proyek.

## Fitur Utama
- **Overview & Metrik Finansial**: Total transfer, akumulasi operasional, dan cash flow.
- **Visualisasi Interaktif**: Chart tren bulanan, distribusi kategori biaya, dan komparasi wilayah via Chart.js.
- **Data Analytics**: Monitoring transfer & summary detail transaksi real-time (pure client-side web application).
- **Responsive & Modern UI**: Tema dark-mode dengan tipografi Plus Jakarta Sans dan tata letak responsif.

## Menjalankan Aplikasi
Aplikasi ini berbasis client-side HTML, CSS, dan JavaScript murni. Cukup buka `index.html` langsung di browser atau gunakan local server:

```bash
# Menggunakan npx serve atau python
python3 -m http.server 8000
```
Lalu buka `http://localhost:8000` di browser.
